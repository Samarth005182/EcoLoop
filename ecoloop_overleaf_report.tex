\begin{abstract}
As e-commerce consumption accelerates globally, digital retail models frequently incentivize disposable single-use items while obscuring environmental realities under vague ``green'' marketing. This project documents the complete user interface, ergonomic system, technical architecture, and sustainability evaluation for \textbf{BEEJAM} (``Shop consciously. Waste less. Live greener.''). Designed specifically for student budgets and conscious households, the platform establishes transparent material disclosure, lifecycle durability assessments, plastic-free shipping standards, and a lightweight digital footprint ($\approx$380~KB average page weight). The complete front-end prototype has been engineered using semantic HTML5, glassmorphism CSS, and vanilla reactive JavaScript, integrated over a dedicated low-carbon ambient visual layer.
\end{abstract}

\section{Introduction and Problem Identification}
Traditional online marketplaces exacerbate environmental degradation through three interconnected vectors:
\begin{enumerate}
    \item \textbf{Greenwashing and Lack of Transparency:} Products are routinely labelled ``natural'' or ``eco-friendly'' based merely on aesthetic kraft packaging, without verifiable raw material percentages or end-of-life disposal pathways.
    \item \textbf{Excessive Packaging and Carbon Overhead:} Small orders frequently arrive in oversized corrugated cartons filled with plastic bubble wraps and polyethylene air pillows.
    \item \textbf{Digital Carbon Footprint:} Modern e-commerce pages average 2.2~MB in size, stuffed with heavy tracking scripts, autoplay video banners, and unoptimized raster assets, each consuming computational and network energy across servers and user devices.
\end{enumerate}
\textbf{BEEJAM} addresses these deficiencies by coupling human-centred design with empirical environmental metrics.

\section{Product Design Requirements}

\subsection{Functional Requirements}
The platform incorporates the following core functional modules:
\begin{itemize}
    \item \textbf{Transparent Catalogue:} Granular categorization (Reusable Hydration, Recycled Paper Stationery, Bamboo Personal Care, Food Storage).
    \item \textbf{Real-Time Filtering and Search:} Interactive budget filtering (e.g., items under ₹500), material composition checkboxes, and instant keyword indexing.
    \item \textbf{Product Detail Evaluation (PDP):} Comprehensive specification matrix providing 100\% raw material breakdown, design lifespan, and end-of-life recycling guidance.
    \item \textbf{Slide-Over Cart Management:} Non-disruptive cart drawer allowing quantity updates, immediate removal, and a live progress indicator toward consolidated zero-carbon ground delivery.
    \item \textbf{Simulated Tokenized Checkout and Order Tracking:} Address entry, delivery packaging selection, UPI integration, and a 4-step progress timeline.
\end{itemize}

\subsection{Non-Functional and Ergonomic Standards}
Following WCAG 2.2 Level AA accessibility guidelines:
\begin{itemize}
    \item \textbf{Touch-Friendly Targets:} Minimum button and interactive dimension of $44 \times 44$~px.
    \item \textbf{High Contrast Readability:} Color contrast exceeds $4.5:1$ using Charcoal (\texttt{\#333333}) on Warm Cream (\texttt{\#F4F0E5}) and Pure White surfaces.
    \item \textbf{Error Prevention:} Inline validation for payment addresses and cart state preservation during navigation.
\end{itemize}

\section{Aesthetics and Visual Design System}
The visual identity utilizes a nature-inspired palette:
\begin{itemize}
    \item \textbf{Forest Green (\texttt{\#2D5B3B}):} Primary identity, navigation, and critical action buttons.
    \item \textbf{Sage Green (\texttt{\#DCE9D5}):} Micro-badges, secondary pills, and interactive highlights.
    \item \textbf{Warm Cream (\texttt{\#F4F0E5}):} Neutral base containers providing comfortable readability.
    \item \textbf{Charcoal (\texttt{\#333333}):} Primary typographic elements.
    \item \textbf{Ambient Poly-Mountain Layer:} Frosted glass panels (\texttt{backdrop-filter: blur(14px)}) over emerald mountain artwork, establishing depth while maintaining clear legibility.
\end{itemize}

\section{Technical Architecture and Student Implementation}
The implementation has been structured for academic viability without unnecessary third-party framework overhead:
\begin{itemize}
    \item \textbf{Frontend Presentation:} Semantic HTML5 and modular CSS3 implementing modern CSS Grid, Flexbox, and Glassmorphism.
    \item \textbf{Client Logic:} Vanilla JavaScript (ES6+) state-driven architecture managing view transitions, filter queries, cart mutations, and notifications.
    \item \textbf{Hosting and Serving:} Lightweight HTTP server architecture serving optimized static assets and SVG vector iconography.
\end{itemize}

\section{Conclusion and Future Scope}
The BEEJAM project demonstrates that sustainable e-commerce web applications can successfully balance aesthetic sophistication, student-friendly price accessibility, and verifiable environmental rigor. Future extensions include circular take-back logistics, localized carbon offset calculations based on logistics postal codes, and WebAssembly-driven client-side packaging volume optimization.
